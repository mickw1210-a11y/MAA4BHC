## 阻碍与下一任务

### W03-04崩溃恢复

命名互斥体在最后句柄关闭后消失。现有日志只由当前项目树内的接口读取，另一副本缺少持久诊断发现与未决动作状态。已有测试复现此缺口。

接续先读device_lease.py、test_device_lease.py、设备调用链与租约说明，研究项目内可实现的持久状态锚点、发现方式和动作核实流程。日志跨副本可读、持有者退出及动作状态均有证据后才能解除该关口。项目外持久化的必要性尚未证明，涉及项目外写入时遵守用户授权边界。具体状态仍以实现与复现实验为准。

W03-07—12需要该恢复前置。当前旧设备入口仍具有开发用连接、截图和受限采集能力，W03安全检查尚待接入。恢复新一轮设备执行前须重新核对授权和现场。
